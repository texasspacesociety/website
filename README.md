# Texas Space Society

The complete Texas Space Society website in a flat GitHub Pages layout.

Every website file is at the repository root—there is no `dist/` folder, asset folder, build folder, or workflow folder.

## Publish with GitHub Pages

1. Upload the contents of this package directly into the root of the `texasspacesociety/website` repository.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, and choose **`/ (root)`**.

GitHub Pages will serve the root `index.html` automatically.

## Edit the board placeholders

Open `index.html` and replace the five board cards marked with placeholder names, roles, photos, and profile links when ready.
